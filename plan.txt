Роли пользователей (3 группы)
Гость (неавторизованный) - может смотреть игры, читать правила, смотреть обзоры. Не может оставлять отзывы или добавлять в избранное.
Клиент (авторизованный) - может всё, что гость, а также добавлять игры в «Избранное», оставлять отзывы, предлагать новые игры.
Администратор - имеет доступ к админ-панели (по адресу /admin, логин/пароль admin / admin11). Обычным пользователям доступ закрыт.

Рубрики сайта (Навигация)
В шапке сайта доступны:
«Главная» (О проекте + Топ-5).
«Каталог» (Все игры + фильтры).
Кнопки «Вход» / «Регистрация» (для гостя) или «Профиль» / «Выход» (для клиента).

Страница «Главная»
Крупный баннер с названием проекта.
Блок «Новинки» (выводятся 4-5 последних добавленных игр: фото, название).
Блок «Топ-5 по рейтингу» (игры с самым высоким средним баллом).

Страница «Каталог»
По умолчанию выводятся все игры (только те, что is_approved = true), отсортированные по алфавиту (или новизне).
Сортировка: по названию (А-Я), по году выпуска, по рейтингу.
Фильтрация: по количеству игроков (например, чекбоксы: «для 1», «для 2», «для компании 4+»).
Каждая карточка: фото, название, мин/макс игроков, средний рейтинг.
Клик по карточке ведет на страницу игры.

Страница «Игра»
Фото, название, описание, издатель, год выпуска, количество игроков.
Блок «Правила» (выводятся списком, каждый пункт можно развернуть - аккордеон).
Блок «Отзывы» (список отзывов пользователей с датой).
Блок «Оценка»: средний балл и форма для выставления своей оценки (1-10).

Регистрация и Авторизация
Форма регистрации: nickname (уникальное), email (уникальное), password (мин. 6 символов), password_repeat.
Валидация: Ошибки выводятся без перезагрузки страницы.
Авторизация: Вход по nickname + password.
Выход: Кнопка сбрасывает сессию и редиректит на главную.

Функционал клиента (Личный кабинет)
Профиль: Смена ника, смена пароля (с вводом старого).
Избранное: Список игр, которые юзер добавил в избранное. Можно удалить из списка.
Предложить игру: Форма добавления новой игры - название и краткое описание. Админ сам находит оригинальные правила и добавляет игру.
Предложить правила: Форма для добавления своих правил для уже существующих игр (уходит в бд со статусом "на модерации")

Функционал администратора (Админка)
Модерация игр: Просмотр предложенных игр. Кнопки «Одобрить» (появляется в каталоге) или «Отклонить/Удалить».
Управление играми: Добавление, редактирование и удаление игр вручную (без модерации).
Просмотр отзывов: Возможность удалить неадекватный отзыв или оценку.
